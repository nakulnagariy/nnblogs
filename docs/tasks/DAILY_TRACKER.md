## 🚀 Quick Start for New Task

1. **Choose task:** Pick from epic task breakdown (1-3 per day)
2. **Copy template:** Use the template above
3. **Fill details:** From task breakdown file
4. **Implement:** Follow technical details & success criteria
5. **Verify:** Check all success criteria
6. **Done:** Mark complete, move to next

---

## ⏱️ Time Management Tips

- **2-hour tasks:** Plan 1-2 per day
- **Focus blocks:** 90 min code, 10 min break, 30 min testing
- **Deadline pressure:** If >2 hours, task might be too big—split it
- **Stuck >30 min:** Ask for help or break into smaller subtasks
